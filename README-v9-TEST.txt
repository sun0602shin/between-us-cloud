우리 사이 v9 Cloud LAB - 전체 기능 통합/서버 수동 동기화 실험판

중요: 기존 v8.3 앱 또는 기존 between-us 저장소를 절대 덮어쓰지 마세요.
between-us-cloud 저장소에만 업로드하고 GitHub Pages를 배포합니다.
브라우저 로컬 DB는 BetweenUsV9CloudLabDB이며 v8.3 DB와 별개입니다.
기존 가족 기록은 자동 이전되지 않습니다. 테스트 데이터만 생성하세요.

1. 기존 v9 메모 테스트가 끝났다면 전체 파일을 between-us-cloud 저장소 최상위에 업로드하세요.
2. Firebase → Firestore Database → Rules에서 firestore-v9.rules 내용으로 교체합니다.
   기존 테스트용 두 UID를 양쪽 PASTE 항목에 다시 채워 넣습니다.
   이전 family-sync-test/notes 접근 규칙도 보존했습니다.
3. 엄마와 딸 모두 Safari에서 새 테스트 앱을 엽니다.
4. 더보기 → Firebase 설정 JSON 붙여넣기 → 연결 → UID가 기존 등록된 UID인지 확인합니다.
5. 새 v9 앱에서 마음 카드, 약속 제안 등 테스트 기록을 각각 1건씩 생성합니다.
6. 서버와 동기화 버튼을 누르고 서로 내려받는지 확인합니다.

주의:
- 보안 규칙은 아직 시험용이며 정식 사용 전 엄마 전용 권한, 수정 충돌, 병합 로직 검증이 필요합니다.
- 날짜 문자열 updatedAt 비교는 두 아이폰 시계가 불일치하면 충돌 가능성이 있습니다.
- 익명 인증의 UID는 Safari 웹사이트 데이터 삭제나 홈 화면 앱 전환 시 달라질 수 있습니다.
- 기존 가족 데이터의 일괄 이전 및 동시 수정은 아직 검증되지 않았습니다.
- private(나만 보기) 마음/카드는 서버에 전송하지 않도록 제외되어 있습니다.
